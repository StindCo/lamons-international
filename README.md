## 02-landing-page/
Site statique d'une page (HTML, CSS et JS, sans dépendance). Ouvrez `index.html` ou déposez le dossier tel quel sur un hébergeur.
Le formulaire ouvre la messagerie de l'internaute avec la demande pré-remplie, adressée à contact@lamonsint.com. Pour un envoi direct, branchez-le sur Formspree, un script PHP ou un service équivalent.
